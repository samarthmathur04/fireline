# Data sources (page labels)

| Feed | Role on the page |
|------|------------------|
| Nominatim | Address → coordinates; ambiguous towns return choices |
| NWS grid | Afternoon fire weather + Red Flag |
| NASA POWER | Days since meaningful rain (≥ 2.5 mm); ~3 day lag |
| NASA FIRMS (3 VIIRS) | Heat detections; flares filtered |
| NIFC WFIGS | Named incidents within 70 km |
| GIBS / NAIP | Orbit frame and lot aerial in extras |
